Zarządzanie rezerwacjami

Jedynym źródłem danych jest plik dostepnosc.js (bez localStorage). Zmiany zapisujesz bezpośrednio do pliku dostepnosc.js (przez File System Access API lub pobranie/skopiowanie pliku).

Nowy wpis rezerwacji

Przeglądarka statyczna (GitHub Pages) nie ma bezpośredniego zapisu na serwer bez autoryzacji – po zmianie kliknij „Zapisz bezpośrednio do dostepnosc.js” (Chrome/Edge) lub „Pobierz dostepnosc.js” i wyślij plik do repozytorium.
